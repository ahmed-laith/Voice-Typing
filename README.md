## دوافع المشروع وقصته
بدأت فكرة أداة Voice Typing من حاجة حقيقية وملموسة: افتقار نظام Windows إلى دعم الإملاء الصوتي باللغة العربية واللهجات المحلية، وخاصة اللهجة العراقية، وصعوبة نطق المصطلحات البرمجية والتقنية الهجينة دون أخطاء مشوهة. 

تمت هندسة وبناء هذا التطبيق ليعمل كأداة كتابة فورية شاملة، تتيح للمستخدم التحدث بحرية مطلقة باللهجة المحكية الممزوجة بأسماء الأدوات والتقنيات باللغة الإنجليزية، لتتحول فورا إلى نصوص نظيفة ومطابقة تماما مكان مؤشر الماوس في أي برنامج.

---

## أبرز المميزات (Key Features)

- 🎙️ **دعم متفوق للعربية واللهجة العراقية وكافة اللهجات:**
  - مجهز بقاموس وتلميحات صوتية ذكية تحافظ على مفرداتك اليومية ولا تفرض الفصحى قسرا.
  - دعم أصيل للحروف الخاصة بالنطق العراقي والعربي: `چ` (چاي، أحچي)، `پ`، `ڤ`، `ڳ`.
- 🔤 **دمج سلس للمصطلحات التقنية اللاتينية:**
  - ينطق المستخدم أسماء الأدوات التقنية مثل `Claude Code`, `Gemini`, `Blender`, `GitHub`, `Terminal`, `API`, `Python` بحروفها اللاتينية الدقيقة وسط الجملة العربية دون تشوه.
- ⚡ **محلي 100% وخفيف على كرت الشاشة:**
  - يعتمد على نموذج `faster-whisper (large-v3-turbo)` على معالج الرسوميات بنمط `int8_float16`.
  - معالجة فائقة السرعة تتجاوز 8.5 أضعاف سرعة الكلام الطبيعي (تسجيل مدته 10 ثوان يعالج في حوالي 1.1 ثانية فقط).
  - ميزة التحرير التلقائي للذاكرة (Auto VRAM Unload) بعد دقائق خمول، ليبقى كرت الشاشة حرا لبرامج المونتاج والتصميم والألعاب.
- 🧠 **مكتبة الإملاءات الذكية وبنك المعرفة (Second Brain):**
  - واجهة ويب عصرية مدمجة (`Voice Typing - Review`) يمكن فتحها مباشرة من قائمة Start أو عبر `review_dictations.bat`.
  - لوحة إحصاءات إنتاجية حية: حساب إجمالي التسجيلات، الكلمات المنطوقة، الساعات الصوتية، والوقت الموفر مقارنة بالكتابة اليدوية.
  - محرك بحث لحظي فائق السرعة (أقل من 2 ميلي ثانية) للبحث في آلاف التسجيلات التاريخية وتصفيتها حسب التاريخ والمدة.
  - مشغل صوتي مدمج مع أزرار تسريع ذكية (`1.0x`، `1.25x`، `1.5x`، `2.0x`) للاستماع السريع.
  - استوديو تحويل فوري بالذكاء الاصطناعي (Gemini Flash Lite):
    - 💡 **تلخيص ومهام:** استخراج أهم النقاط وقوائم المهام من أفكارك الصوتية.
    - 🤖 **تحويل إلى برومبت (Promptify):** تحويل التسجيل الشفوي إلى برومبت تنفيذي متقدم وموجه لوكلاء الذكاء الاصطناعي (Claude Code / Antigravity).
    - ✉️ **صياغة رسمية:** تحويل الكلام العفوي إلى بريد إلكتروني أو رسالة رسمية أنيقة.
    - ✍️ **تصفية التأتأة والتردد:** تنظيف فوري للنص مع بقاء كلماتك الأصلية.
  - زر تصدير شامل للأرشيف المفلتر بصيغة Markdown بنقرة واحدة لتضمينه في Notion و Obsidian.
  - إضافة المصطلحات الجديدة فورا إلى ملف `vocabulary.txt` بضغطة زر.
- 🎯 **اختصار عالمي سلس (F1):**
  - فقاعة عائمة دائرية لا تسحب التركيز، تكتب النص مكان المؤشر في أي برنامج (محررات الأكواد، المتصفحات، برامج التصميم، تطبيقات المحادثة).

## متطلبات التشغيل والأداء (Hardware & Benchmarks)

| المكون | المواصفات المقترحة | الحد الأدنى لتشغيل الأداة |
|---|---|---|
| نظام التشغيل | Windows 10 / 11 (64-bit) | Windows 10 (64-bit) |
| المعالج (CPU) | Intel Core i5 من الجيل العاشر فما فوق / AMD Ryzen 5 | معالج رباعي النواة حديث |
| كرت الشاشة (GPU) | NVIDIA RTX (RTX 3050 فأعلى) بذاكرة 4GB VRAM أو أكثر | NVIDIA GTX مع كودا (CUDA) أو العمل على المعالج (CPU) |
| الذاكرة العشوائية (RAM) | 16GB DDR4/DDR5 | 8GB RAM |
| سرعة المعالجة | معالجة فورية بنحو 8.6x سرعة الوقت الفعلي (Realtime Speedup) | معالجة فورية تتراوح بين 2x إلى 4x |

## التثبيت والتشغيل السريع (Quick Start)

### خطوات التثبيت بضغطة زر
1. قم بتحميل أو استنساخ المستودع (Clone / Download ZIP):
   ```bash
   git clone https://github.com/ahmed-laith/Voice-Typing.git
   cd Voice-Typing
   ```
2. اضغط مرتين على ملف **`setup.bat`**.
3. سيقوم المثبت التلقائي بإنشاء البيئة وتثبيت المكتبات، ووضع اختصار للأداة واختصار للمكتبة في **سطح المكتب** و**قائمة ابدأ (Start)**.
4. اضغط **F1** وتكلم بحرية!

للاطلاع على كتيب التعليمات اليومي، انظر: [GUIDE.md](GUIDE.md).

## التكوين والإعدادات (`config.json`)

| الإعداد | الوصف | القيمة الافتراضية |
|---|---|---|
| `hotkey` | مفتاح الاختصار السريع لفتح وإغلاق النافذة | `"f1"` |
| `language_mode` | نمط الكشف اللغوي (`smart`, `ar`, `en`) | `"smart"` |
| `model` | نموذج Whisper المعتمد محليا | `"large-v3-turbo"` |
| `beam_size` | حجم شعاع فك التشفير (خفيف وسريع) | `3` |
| `unload_model_after_minutes` | تحرير ذاكرة كرت الشاشة VRAM بعد دقائق من الخمول | `10` |
| `llm_cleanup` | تفعيل التنظيف والتحويل الذكي بالذكاء الاصطناعي | `true` |
| `llm_provider` | مزود الذكاء الاصطناعي (`gemini` أو `claude`) | `"auto"` |
| `gemini_model` | موديل المعالجة السريعة فائق الخفة | `"gemini-flash-lite-latest"` |

## تفعيل خدمات الذكاء الاصطناعي (Gemini Flash)
1. احصل على مفتاح API مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey).
2. احفظ المفتاح في ملف نصي باسم `gemini_key.txt` داخل مجلد البرنامج.
3. يعمل التفعيل فورا وبشكل لحظي دون الحاجة لإعادة تشغيل الأداة.

- كافة التسجيلات الصوتية والنصوص المخزنة تبقى **محليا 100%** على حاسوبك الشخصي.
- لا يتم إرسال أي صوت أو تسجيل عبر شبكة الإنترنت.
