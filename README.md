## 🌟 أبرز المميزات (Key Features)

- 🎙️ **دعم فائق للهجة العراقية وكافة اللهجات العربية:**
  - مجهز بقاموس وتلميحات صوتية تحافظ على ألفاظك المحلية ولا تحولها قسراً إلى فصحى متكلفة.
  - دعم أصيل للحروف الخاصة بالنطق العربي والعراقي: `چ` (چاي، أحچي)، `پ`، `ڤ`، `ڳ`.
- 🔤 **خلط سلس بين العربي والمصطلحات الإنجليزية:**
  - ينطق المستخدم أسماء الأدوات التقنية مثل `Claude Code`, `Gemini`, `Blender`, `GitHub`, `Terminal`, `API` بحروفها اللاتينية الدقيقة وسط الجملة العربية دون تشوه.
- ⚡ **محلي 100% وخفيف على النظام:**
  - يعتمد على نموذج `faster-whisper (large-v3-turbo)` على كرت الشاشة بنمط `int8_float16`.
  - يفرغ الذاكرة تلقائياً بعد فترة خمول ليترك كرت الشاشة حراً للمونتاج والألعاب والتصميم.
- 🧠 **تنظيف وتصحيح ذكي (Smart LLM Polish):**
  - دعم مدمج لـ `Google Gemini Flash` و `Anthropic Claude` لحذف التأتأة وتصحيح الكلمات بالمعنى وسياق الجملة في ثانية واحدة.
- 🎯 **اختصار عالمي سريع (F1):**
  - نافذة عائمة دائرية لا تسحب التركيز، تكتب النص مكان المؤشر في أي برنامج (محررات الأكواد، المتصفحات، برامج التصميم، تطبيقات المحادثة).
- 🛠️ **تعلم وتطوير ذاتي:**
  - إمكانية إضافة مصطلحاتك وقواعد الاستبدال فورياً عبر `vocabulary.txt` و `corrections.txt`.
  - لوحة مراجعة محلية عبر المتصفح (`review_dictations.bat`) لاقتراح القواعد بنقرة واحدة.

## 🚀 التثبيت والتشغيل السريع (Quick Start)

### المتطلبات الأساسية
- نظام **Windows 10 / 11**.
- كرت شاشة **NVIDIA GPU** (يُفضل 4GB VRAM أو أكثر) أو معالج قوي.
- برنامج **Python 3.10+** مثبت ومضاف للـ PATH.

### خطوات التثبيت بضغطة زر
1. قم بتحميل أو استنساخ المستودع (Clone / Download ZIP).
2. اضغط مرتين على ملف **`setup.bat`**.
3. سيقوم المثبت التلقائي بإنشاء البيئة وتثبيت المكتبات، ووضع اختصار للأداة على **سطح المكتب** و**قائمة ابدأ**.
4. اضغط **F1** وتكلم بحرية!

للاطلاع على كتيب التعليمات المختصر، انظر: [GUIDE.md](GUIDE.md).

## ⚙️ التكوين والإعدادات (`config.json`)

| الإعداد | الوصف | القيمة الافتراضية |
|---|---|---|
| `hotkey` | مفتاح الاختصار السريع لفتح وإغلاق النافذة | `"f1"` |
| `language_mode` | نمط الكشف اللغوي (`smart`, `ar`, `en`) | `"smart"` |
| `model` | نموذج Whisper المعتمد محلياً | `"large-v3-turbo"` |
| `beam_size` | حجم شعاع فك التشفير (خفيف وسريع) | `3` |
| `unload_model_after_minutes` | تحرير VRAM بعد دقائق من عدم الاستخدام | `10` |
| `llm_cleanup` | تفعيل التنظيف الذكي للتأتأة والتردد | `true` |
| `llm_provider` | مزود الذكاء الاصطناعي (`gemini` أو `claude`) | `"auto"` |
| `gemini_model` | الموديل الخفيف للتنظيف السريع | `"gemini-flash-lite-latest"` |

## 🔑 تفعيل التنظيف الذكي (Gemini Flash)
1. احصل على مفتاح API مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey).
2. احفظ المفتاح في ملف نصي باسم `gemini_key.txt` داخل مجلد البرنامج.
3. التفعيل فوري وبدون إعادة تشغيل!
