# Fix words that Whisper keeps getting wrong. One rule per line:   wrong text => right text
# Rules match whole words only ("شاي" does not touch "شايف"). Arabic rules also match with the
# prefixes و ف ب ل ك ال ("والشاي" -> "والچاي"). A * at the end keeps the word's ending:
# "أحكي* => أحچي*" turns "أحكيلك" into "أحچيلك". Latin words ignore upper/lower case.
# Applied after every dictation, no restart needed.
# You can also add rules by running:  .venv\Scripts\python voice_typing.py --learn
#
# Examples (remove the # to enable):
# clode code => Claude Code
# كلود كود => Claude Code
# هاي فيلد => Higgsfield
